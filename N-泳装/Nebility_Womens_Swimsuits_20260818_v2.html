Nebility 的进入权

Zone 塑形 / Power Mesh

迁移方式从腹部强压改为水环境的分区稳定

迁移限制水会改变弹性、吸水、压感

新增能力湿态压强与回复验证

Curve / Fit Knowledge

迁移方式Regular / Long Torso / Curvy / 胸部支撑

迁移限制泳装多一个肩-裆体长与胸部水中稳定变量

新增能力泳装专属 block + Fit Clinic

Seamless / Stretch Comfort

迁移方式减少硬边、提高动作舒适

迁移限制并非所有无缝材料耐氯 / 适合湿态

新增能力泳装材料与缝制验证

尺码 Inclusivity

迁移方式S–4X + 多体型试穿

迁移限制不能只放大纸样

新增能力独立 Curvy / Long 版型资源

证据-Led Content

迁移方式把塑形表达转成湿态、动作、结构 RTB

迁移限制不可用羞耻型 before/after 或未经验证厘米承诺

新增能力A+ / Video 证据体系

Amazon Operation

迁移方式搜索、页面、广告、评价积累

迁移限制泳装强季节，评价爬坡时间更短

新增能力Jan Soft 上市 + 核心色库存

哪些塑身衣做法不能直接迁移

不要复制整件高压 / 骨条式强约束

水中会放大厚重、吸水、穿脱与不适。

不要复制“显瘦十斤 / 修复身材”叙事

不可验证，也与身体包容定位冲突。

不要复制统一围度放码

泳装必须同时处理 torso、bust、hip、leg opening。

不要复制只靠干态 Before / After

真正 RTB 必须发生在 Wet-State 与动作中。

本轮包含
Black；一个主领型；分区 power mesh；underbust / 侧托；稳定杯；可调宽肩带；Regular + Long Torso；核心跳码样衣覆盖 S–4X 关键体型。
本轮暂不纳入
Navy / Cocoa 时尚扩色、Full Bust 专项、UPF 强宣称、premium trims、复杂配件、波次 2 结构。
测试方法
36–48 人 Fit Clinic + 24 人 5–10 次泳池 / 家测 + 概念 / 价格测试；通过后再进入小单 Amazon Pilot。
通过标准
核心结构在湿态稳定、胸部安全、肩裆舒适上优于对标；用户能正确复述差异；$39.99–44.99 WTP 有效；无不可控 S–4X Fit 问题。
未通过处理
若“湿态也稳”用户无感 → 重构 Hero 命题；若 Long / Curvy 成本与库存不可控 → 降低 Fit variant；若强塑形必须牺牲舒适 → Kill 强塑形路线，改为 Stability / Support。
核心区别：Hero 是“我们最终希望靠什么产品赢”；MVP 是“用最低必要复杂度验证我们有没有资格去赢”。MVP 不是低配版。

本轮可以批准“验证”，还不能批准“完整投资”

现在可以决定

  • 类目可进入，但以塑形泳装系统而非低价罩衫 / 纯时尚比基尼为入口。
  • P0 = 连体 + Tankini；P1 = Modern Swim Dress。
  • S1 CoreSculpt One-Piece 是唯一 Hero。
  • 品牌命题 = Shapewear That Can Swim；核心 +1 = Wet-State Sculpt + Fit 版型架构。
  • Hero 价格方向 = $39.99；核心升级层 = $42.99–44.99。
  • 2027 Jan Soft 上市；Mar–Jul Scale；2026 Dec 前量产冻结。

现在还不能决定

  • 最终首单量、Contribution Margin 与是否允许全 波次 1 同时量产。
  • Regular / Long / Curvy / Full Bust 的最终版型数量与尺码覆盖。
  • 固定杯 / 半固定杯、Tankini 防上浮、泳裙安全裤的最终结构。
  • UPF 50+ 是否作为上市主卖点。
