# 04_数据判断标准.md  
## 新品概念验证数据判断标准

---

## 一、核心判断逻辑

新品用户调研不是为了证明“我们想做的产品一定对”，而是为了用最低成本判断：

```text
用户痛点是否真实
↓
痛点是否足够强
↓
新品概念是否能被理解
↓
用户是否愿意买
↓
用户是否愿意为差异化付费
↓
开发风险是否可解决
↓
是否值得进入下一阶段
```

---

## 二、关键指标与通过标准

| 指标 | 建议通过标准 | 说明 |
|---|---:|---|
| 有效品类用户占比 | ≥70% | 样本基本可用 |
| 目标产品相关用户占比 | ≥30% | 与新品方向相关 |
| 核心痛点选择率 | ≥40% | 痛点真实存在 |
| 痛点严重度4-5分 | ≥35% | 痛点足够强 |
| 概念兴趣 A+B | ≥60% | 用户理解并感兴趣 |
| 强购买兴趣 | ≥40% | 有转化潜力 |
| 愿意溢价 | ≥30% | 有差异化价值 |
| 主要担忧可解决 | 是 | 能继续推进开发 |

---

## 三、指标定义

### 1. 有效品类用户占比

适合计算为：

```text
穿过 / 买过 / 愿意尝试该品类的人数 ÷ 总样本量
```

例如塑身衣问卷中，以下都可以算有效样本：

- 经常穿塑身衣；
- 偶尔穿塑身衣；
- 买过但很少穿；
- 没买过但感兴趣。

不建议纳入有效样本：

- 没买过，也不感兴趣。

---

### 2. 目标产品相关用户占比

例如后拉式易穿脱塑身衣，目标相关用户可以包括：

- 穿过连体塑身衣；
- 考虑购买连体塑身衣；
- 经常在婚礼/通勤/旅行/连衣裙场景穿塑身衣；
- 明确反馈如厕不便的人。

---

### 3. 核心痛点选择率

适合计算为：

```text
选择核心痛点相关选项的人数 ÷ 有效样本量
```

如果一个痛点由多个选项共同构成，可以合并计算。

例如“如厕不便”可由以下选项构成：

- Difficult to take off when using the bathroom；
- Need to remove straps or take off the whole bodysuit；
- Hard to put it back on after using the bathroom；
- Crotch opening is not convenient or hygienic。

只要用户选择其中任意一项，就可以计入“如厕痛点用户”。

---

### 4. 痛点严重度 4-5 分占比

适合计算为：

```text
痛点严重度评分为 4 或 5 的人数 ÷ 有效样本量
```

判断标准：

| 4-5分占比 | 判断 |
|---:|---|
| ＜20% | 痛点较弱 |
| 20%-35% | 有痛点，但不一定足以支撑新品 |
| 35%-50% | 痛点明确，值得继续验证 |
| ＞50% | 强痛点，具备新品机会基础 |

---

### 5. 概念兴趣 A+B

通常计算为：

```text
Very interested + Somewhat interested
```

判断标准：

| 概念兴趣占比 | 判断 |
|---:|---|
| ＜40% | 概念吸引力弱 |
| 40%-60% | 有兴趣，但需优化表达 |
| 60%-75% | 概念吸引力较好 |
| ＞75% | 概念吸引力强 |

---

### 6. 强购买兴趣

建议不要把所有 “Maybe” 都算强购买兴趣。

例如：

| 选项 | 是否算强购买兴趣 |
|---|---|
| Yes, definitely | 是 |
| Maybe, if the fit and shaping are good | 是，条件型强兴趣 |
| Maybe, if the price is reasonable | 不建议算强兴趣，更偏价格敏感 |
| Not sure | 否 |
| No | 否 |

---

### 7. 愿意溢价

适合计算为：

```text
明确愿意多付 $5-$10 或 $10-$15 的人数 ÷ 有效样本量
```

`Maybe, depending on the quality` 可以单独列为“条件型溢价”，不建议直接算明确溢价。

## 四、综合决策矩阵

### A. 建议推进

| 指标 | 表现 |
|---|---|
| 样本有效性 | 高 |
| 痛点选择率 | 高 |
| 痛点严重度 | 高 |
| 概念兴趣 | 高 |
| 购买兴趣 | 高 |
| 溢价能力 | 中高 |
| 用户担忧 | 可通过产品解决 |

建议动作：

```text
进入样衣开发
↓
筛选10-15名高兴趣用户深访
↓
做试穿测试
↓
优化结构和尺码
↓
准备MVP小批量测试
```

---

### B. 建议优化后再验证

| 指标 | 表现 |
|---|---|
| 样本有效性 | 可用 |
| 痛点选择率 | 中高 |
| 痛点严重度 | 中 |
| 概念兴趣 | 一般 |
| 购买兴趣 | 一般 |
| 用户担忧 | 较集中 |

建议动作：

```text
优化产品概念图
↓
优化卖点表达
↓
补充竞品/VOC证据
↓
二次问卷或小样本访谈
```

---

### C. 建议暂缓

| 指标 | 表现 |
|---|---|
| 样本有效性 | 低 |
| 痛点选择率 | 低 |
| 痛点严重度 | 低 |
| 概念兴趣 | 低 |
| 购买兴趣 | 低 |
| 用户更关注其他痛点 | 是 |

建议动作：

```text
暂缓该方向
↓
回到更高频痛点
↓
重新定义机会点
```

---

## 五、风险提示

以下情况下，不建议直接下结论：

1. 样本量低于 30；
2. 有效样本占比低于 50%；
3. 问卷只问了 Yes/No，没有痛点题；
4. 没有概念图或概念解释；
5. 样本不是品类用户；
6. 开放题反馈与选择题结果明显冲突；
7. 只有兴趣数据，没有购买意向和担忧点数据。
