# 老板汇报启动词模板

复制以下内容，填入【】中的信息后发给 AI。

```text
启动【新品调研老板汇报文档生成 Skill】

项目名称：
【例如：后拉式易穿脱塑身衣】

调研方式：
【例如：Google Form 社群问卷】

【例如：共回收86份，有效样本72份】

【例如：品牌现有海外社群用户，非精准定向N用户，但愿意回复者基本是塑身衣购买或兴趣用户】

1. 有效品类用户占比：【例如：78%】
2. 目标产品相关用户占比：【例如：46%穿过或考虑购买连体塑身衣】
3. 核心痛点选择率：【例如：58%反馈如厕麻烦】
4. 痛点严重度4-5分占比：【例如：42%】
5. 概念兴趣A+B：【例如：67%】
6. 强购买兴趣：【例如：45%】
7. 愿意溢价：【例如：32%愿意多付$5-$10】

用户主要喜欢点：
1. 【喜欢点1】
2. 【喜欢点2】
3. 【喜欢点3】

用户主要担忧点：
1. 【担忧点1】
2. 【担忧点2】
3. 【担忧点3】

开放题高频 VOC：
1. 【VOC1】
2. 【VOC2】
3. 【VOC3】

请输出：
1. 一句话结论
2. 8-10页老板汇报文档结构
3. 每页标题、核心目的、正文内容、图表建议
4. 数据解读
5. 产品开发启示
6. 综合判断：推进 / 优化后再验证 / 暂缓
7. 下一步行动建议
```
