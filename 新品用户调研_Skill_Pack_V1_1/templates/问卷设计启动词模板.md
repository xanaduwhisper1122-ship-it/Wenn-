# 问卷设计启动词模板

复制以下内容，填入【】中的信息后发给 AI。

```text
启动【新品用户调研问卷设计 Skill】

新品方向：
【例如：后拉式易穿脱塑身衣】

产品概念：
【用1-3句话说明产品是什么、解决什么问题、差异化是什么】

调研对象：
【例如：品牌现有海外社群用户，非精准定向N用户，但愿意回复者基本是塑身衣购买或兴趣用户】

调研渠道：
【例如：Google Form + 社群发帖】

本次想验证：
1. 【用户是否存在该痛点】
2. 【用户是否理解并喜欢新品概念】
3. 【用户是否愿意购买】
4. 【用户是否愿意为该功能/结构支付更高价格】
5. 【用户主要担忧点是什么】

特殊要求：
1. 问卷以英文输出；
2. 题目控制在 10-15 题；
3. 题型以单选、多选、1-5分量表和开放题为主；
4. 不使用 Google Forms 原生 Other；
5. Other 统一写成 “Other (please specify below)”；
6. 额外增加可选开放题 “If you selected Other, please specify:”；
7. 输出 Google Sheet 可粘贴版，字段为：
section | question | type | options | required | description
8. type 只允许：
single / multiple / dropdown / scale / short / paragraph
9. options 多个选项用英文竖线 | 分隔；
10. required 用 TRUE 或 FALSE。

请输出：
一、调研定位
二、核心研究假设
三、Google Form 标题
四、问卷开头英文文案
五、正式问卷题目：中文解释版
六、正式问卷题目：英文可复制版
七、Google Sheet 可粘贴版
八、图片/概念展示建议
九、社群发帖英文文案
十、数据判断标准
十一、结果解读方法
十二、后续建议
```
